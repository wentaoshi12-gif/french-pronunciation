# Parlons · French Handbook Read-Aloud

本仓库提供最新版法语手册的46页逐页点读站，原PDF高清页面，支持单词/句子点击朗读、连续滚动、翻页和语速调节。

网站另含与讲义配套的 A1 听力训练：16组原创对话，覆盖自我介绍、日常作息、住房、购物、复合过去时、身体健康、命令式、副动词、代词 `y` 和综合复习。听力页支持变速、逐句播放、选择题自动评分、听写检查、原文显示与本地学习进度；`listening-workbook.pdf` 是同编号的24页打印分册。

启用 GitHub Pages：Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。

请确认手册全文、教材内容及其中的姓名和个人资料适合公开发布。公开仓库中的网站文件和原PDF均可被公众访问。

浏览器语音使用 Web Speech API，播放能力取决于浏览器及系统所安装的法语声音；本网站不提供发音准确率评分。听力内容和学习进度均保存在前端，网站不会上传答题记录。
